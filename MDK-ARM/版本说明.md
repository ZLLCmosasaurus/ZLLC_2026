## 25/12/08
### 机械臂逆解算控制实现
基于[交龙战队机器人学开源库](https://github.com/SJTU-RoboMaster-Team/Matrix_and_Robotics_on_STM32)对当前构型机械臂(类PUMA，Y-P-P-R-P-R)进行建模并实现了解析法的求逆解算法，实测求一个点的一组逆解耗时稳定在在 **`3ms±0.1ms`** 左右，求解过程放在前台循环中进行

将求解结果代入MATLAB中验证无误，筛选出的在限位范围内的合法解应用到电机控制上实现的位置和姿态较为准确，各关节误差在5°以内

-8.44rad    -28.6rad
-3.44rad    -21.2rad
-3.26rad    -21.17rad

## 键位

**模式切换**
| 按键 | 触发方式 | 切换结果 |
|---|---|---|
| `Z` | 松开触发 | `WORKING` |
| `X` | 松开触发 | `MOVING` |
| `C` | 松开触发 | `UPLIFT` |
| `V` | 松开触发 | `DOWNLIFT` |
| `Shift + Z` | 松开触发 | `SAVE_LOAD`，`Unit 1` |
| `Shift + X` | 松开触发 | `SAVE_LOAD`，`Unit 2` |

**通用键鼠**
| 键位 | 生效范围 | 功能 |
|---|---|---|
| `W / S` | 所有键鼠模式，`DISABLE` 除外 | 底盘前进 / 后退 |
| `A / D` | 所有键鼠模式，`DISABLE` 除外 | 底盘左移 / 右移 |
| `鼠标 X`（右键未按） | 所有键鼠模式，`DISABLE` 除外 | 底盘转向 / Yaw 控制 |
| `B` | 键鼠模式 | 松开触发，切换车头朝向 `FOREHEAD/REARBACK`，并把 `VT03_Yaw` 设为 `0/180`，同时强制回到手动云台朝向 |
| `Shift + B` | 键鼠模式 | 松开触发，切换 `VT03_Yaw_Control_Type`：`MANUAL/FOLLOW` |
| `Shift + Q` | 键鼠模式 | 松开触发，请求抬升机构重新标定 |
| `R` | 键鼠模式 | 松开触发，请求 UI 全量刷新 |
| `鼠标右键按住 + 鼠标移动` | `SAVE_LOAD` 以外 | 控制 `VT03` 视角；`Mouse Y` 调 Pitch，`Mouse X` 在 `MANUAL` 下调 Yaw |
| `Shift` | 键鼠模式 | 速度倍率按模式变化，见下表 |

**速度倍率**
| 模式 | `Shift` 未按 | `Shift` 按下 |
|---|---|---|
| `MOVING` | `1.0` | `0.5` |
| `WORKING` | `0.25` | `0.5` |
| `SAVE_LOAD` | `0.25` | `0.5` |
| `UPLIFT` | `1.0` | `1.0` |
| `DOWNLIFT` | `0.5` | `1.0` |

**分模式键位**
| 模式 | 键位 | 功能 |
|---|---|---|
| `WORKING` | `Q / E` | 1 号抬升机构上升 / 下降 |
| `WORKING` | 机械臂目标 | 来自自定义控制器数据，不是当前键盘逐关节直控 |
| `SAVE_LOAD` | `Q / E` | 1 号抬升机构上升 / 下降 |
| `SAVE_LOAD` | `鼠标左键` | 松开触发，夹爪开合切换 |
| `SAVE_LOAD` | `鼠标右键` | 松开触发，确认存取矿 FSM 下一步 |
| `UPLIFT` | `Ctrl` | 松开触发，小轮从动开关翻转 |
| `UPLIFT` | `Shift + R` | 按住时置 `backdoor_jump = true` |
| `UPLIFT` | `Shift + C` | 按住时置 `uplift_fsm_direction = FORWARD` |
| `DOWNLIFT` | `Q / E` | 0、1 号抬升机构同时上升 / 下降 |
| `DOWNLIFT` | `F / G` | 2、3 号抬升机构同时上升 / 下降 |
| `DOWNLIFT` | `Ctrl` | 松开触发，小轮从动开关翻转 |

**遥控器拨杆/摇杆**
| 控制器 | 键位 | 功能 |
|---|---|---|
| `DR16` | 左拨杆 `UP / MID / DOWN` | 切到 `DISABLE / MOVING / WORKING` |
| `VT13` | 模式拨钮 `Left / Middle / Right` | 切到 `DISABLE / MOVING / WORKING` |
| `DR16` / `VT13` | 左摇杆 X/Y | 底盘平移 |
| `DR16` / `VT13` | 右摇杆 X | 底盘转向 / Yaw |
| `DR16` / `VT13` | 右摇杆 Y | 在 `WORKING` 模式下控制 1 号抬升机构上升 / 下降，阈值约 `±0.85` |
| `DR16` | 右拨杆 `DOWN` | 在 `WORKING` 模式下，小轮从动强制 `ON`；否则 `OFF` |
